# TeleBackup

🌐 **English:** [README.md](README.md)

Вас когда-нибудь исключали из группового чата, где осталась куча важных фотографий? Удаляли ли у вас личную переписку, после чего приходилось судорожно искать общие воспоминания с важным человеком? Или, возможно, вы помните, что кто-то написал конкретную фразу, но когда заходите позже, то видите пометку «изменено» и уже не можете вспомнить исходный текст?

Для всех этих проблем есть единое решение: локальный Telegram бэкапер и офлайн веб-просмотрщик на Python (Telethon + Flask), SQLite и чистом JavaScript.

TeleBackup скачивает чаты, каналы, группы и медиафайлы на диск и позволяет просматривать их через локальный веб-интерфейс (`127.0.0.1:8000`), похожий на Telegram Desktop. Поскольку просмотрщик читает данные напрямую из локальной базы SQLite и папки `media_backup/`, архив остаётся целым и доступным для поиска, даже если сообщения позже отредактируют, удалят или сам чат станет недоступен в Telegram (при условии, что скрипт был запущен во время этих событий).

## Возможности

* **Инкрементальное и возобновляемое резервное копирование:** Создавайте бэкапы полной истории чатов или выбранных диапазонов дат через Web UI или консольный CLI. Если крупная загрузка прервалась из-за сбоя сети или ограничений Telegram (FloodWait), её можно продолжить в любом направлении (`latest_first` или `older_first`) либо запустить сверку пропусков для проверки удалённых диапазонов сообщений без повторного сканирования всего чата.
* **Гибкая фильтрация медиа:** Настраивайте лимиты размера по категориям медиа (фото, видео, голосовые сообщения, видеосообщения, кружки, документы) глобально или для отдельного чата. Также можно исключить конкретных пользователей, инлайн-ботов или пересланные сообщения от ботов (например, ботов-загрузчиков медиа), чтобы они не засоряли диск, сохранив при этом их текст и возможность скачать эти файлы позже.
* **Живой архиватор 24/7:** Пассивно работает в фоне и сохраняет входящие сообщения, реакции, правки и удаления в реальном времени без отправки отметок о прочтении. Предыдущие версии изменённых сообщений сохраняются в раскрываемой истории правок, а удалённые сообщения помечаются визуально (`is_deleted`), не исчезая из вашей базы данных.
* **Быстрый поиск и кросс-чатовый инспектор (Investigator):** Мгновенный полнотекстовый поиск на базе SQLite FTS5, навигация по календарю дат и локальный поиск внутри чата (`Ctrl+F`). Для глубокого анализа встроенный Investigator позволяет фильтровать сообщения сразу по всем чатам - по отправителю, источнику пересылки, типу медиа, размеру файла и диапазону дат, с опциональным экспортом в CSV.
* **Офлайн-транскрибация голосовых и видеосообщений:** Опциональное локальное распознавание речи на базе `faster-whisper` и `PyAV`. Расшифровывайте отдельные голосовые сообщения и кружки по нажатию кнопки или запускайте фоновую очередь для всего чата. Расшифровки индексируются в SQLite, поэтому сказанное в аудио находится обычным текстовым поиском.
* **Инспектор медиа-активов:** Проверяйте состояние медиафайлов чата: что уже скачано, что пропущено по правилам фильтрации или отсутствует; оценивайте объём докачки, скачивайте отдельные недостающие файлы или массово экспортируйте медиа в выбранную папку.
* **Поддержка нескольких аккаунтов и устройств:** Переключайтесь между несколькими сессиями Telegram прямо из интерфейса (поддерживается вход по QR-коду и по номеру телефона с 2FA). Если вы делаете бэкапы на разных компьютерах, неразрушающее слияние баз данных (`Настройки → Дополнительно`) объединит внешние базы SQLite и папки с медиа в ваш основной архив.
* **Локальная защита доступа:** Привязка к `localhost` и защита с помощью PIN-кода доступа (по умолчанию генерируется автоматически, можно задать свой).

## Быстрый старт

### 1. Получите API-ключи Telegram

1. Войдите на [my.telegram.org](https://my.telegram.org) и откройте **API development tools**.
2. Создайте приложение и скопируйте ваши `api_id` и `api_hash`.

### 2. Настройка

Если вы не уверены, как редактировать конфигурационные файлы, откройте их любым текстовым редактором (например, Блокнотом).

Переименуйте `config.ini.example` в `config.ini` и впишите свои данные:

```markdown
[Telegram]
api_id = ваш_api_id
api_hash = ваш_api_hash
session_name = что_угодно 

[Backup]
media_dir = media_backup
max_file_size_mb = 20     # используется только для CLI-режима, у Web UI свои настройки
download_workers = 3      # количество потоков загрузки; при частых лимитах TG уменьшите значение
```

*(Опционально)* Переименуйте `.env.example` в `.env`, если хотите задать постоянный пользовательский PIN-код для Web UI.

### 3. Установка зависимостей

Требуется Python 3.10+. Если планируете использовать распознавание речи (Whisper), отредактируйте `requirements.txt`, чтобы разрешить установку зависимостей для него. Если не уверены, какие зависимости уже установлены, просто запустите команду и она доставит недостающие.

```bash
pip install -r requirements.txt
```

### 4. Запуск

Используйте `run.bat` или `run.sh`

ИЛИ

Откройте терминал (cmd) в папке проекта (или перейдите в неё вручную) и запустите веб-сервер:

```bash
python app.py
```

1. Откройте `http://localhost:8000` в браузере.
2. Введите **PIN-код доступа**, напечатанный в терминале (или ваш пользовательский `TELEBACKUP_PIN`).
3. Войдите в аккаунт Telegram через Web UI с помощью **QR-кода** (рекомендуется) или **Телефона + кода**, либо авторизуйтесь через терминал командой `python cli.py`. Если вход через Web UI не срабатывает, авторизация через терминал обычно решает проблему — после входа просто обновите открытую страницу.

Для автономного бэкапа без запуска веб-сервера укажите `chat_ids` в `config.ini` и выполните:

```bash
python cli.py
```

## Опционально: локальное распознавание речи (Whisper)

Чтобы включить офлайн-транскрибацию голосовых сообщений и видеосообщений-кружков:

```bash
pip install faster-whisper av
python tools/setup_whisper.py
```

После установки откройте **Настройки → Дополнительно → Распознавание речи (Whisper)** в Web UI, чтобы скачать, переключить или удалить модели (`tiny`, `base`, `small`, `medium`, `large-v3-turbo`), а также задать собственную папку для хранения моделей. Аппаратное ускорение (`CUDA / float16` на видеокартах NVIDIA или `CPU / int8` по умолчанию) выбирается автоматически.

## CLI и утилиты обслуживания

Вспомогательные скрипты находятся в папке `tools/` и запускаются из корня проекта:

| Команда                              | Описание                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `python tools/db_export.py`               | Экспорт истории чата в Markdown (`.md`) с разбивкой по дням, неделям, месяцам, произвольному периоду или в один файл (интерактивно или через флаги CLI; поддержка EN/RU).                                                                        |
| `python tools/import_tg_export.py <path>` | Импорт официальной выгрузки Telegram Desktop в формате JSON/HTML (`result.json` + медиафайлы) в базу данных SQLite.                                                                                                                                                                                           |
| `python tools/dedup_hardlinks.py`         | Дедупликация одинаковых медиафайлов (>64 КБ) между папками чатов с помощью жёстких ссылок (hardlinks) без нарушения относительных путей. Файлы остаются доступны в каждом чате, но занимают меньше места. |
| `python tools/setup_whisper.py`           | Установка и проверка `faster-whisper` и `PyAV` для локального распознавания речи.                                                                                                                                                                                                                                |
| `python tools/update.py`                  | Загрузка последней версии с GitHub и запуск миграций базы данных. Аналогично обновлению через окно настроек Web UI.                                                                                                                                                             |

## Горячие клавиши

* `Ctrl + K` или `/` — Глобальный поиск по всем чатам
* `Ctrl + F` — Поиск внутри текущего чата
* `Esc` — Закрыть активное окно, просмотрщик медиа (lightbox) или панель поиска
* `Влево / Вправо` — Предыдущий / следующий медиафайл в просмотрщике
* `?` — Открыть шпаргалку по горячим клавишам
